# Atlas Transportation

Transportation maps for the World of Warcraft Atlas addon.

Atlas Transportation is an optional Atlas plugin for browsing transportation
nodes on the maps included in the package. It requires the Atlas core addon
and does not run as a standalone addon.

## Downloads

- [Atlas Transportation on CurseForge](https://www.curseforge.com/wow/addons/atlas-transportation)
- [Atlas core addon on CurseForge](https://www.curseforge.com/wow/addons/atlas)

Choose releases compatible with your WoW client. Available maps and information
may vary by release.

## Installation

1. Install the Atlas core addon.
2. Install Atlas Transportation for the same WoW client.
3. Enable both addons in the character selection screen's AddOns list.
4. Open Atlas with `/atlas` and select the transportation maps.

For manual installation, extract the addon into the `Interface/AddOns`
directory of the WoW client you use. Preserve the addon folder structure
and avoid an extra wrapper folder.

## About This Plugin

Atlas Transportation was originally included in Atlas. It is now distributed
as a separate addon so players can choose whether to install its maps.

This repository contains the Atlas Transportation plugin, not the Atlas core.

## Bug Reports and Contributions

Please use this repository's Issues page to report bugs or suggest improvements.

For bug reports, include:

- WoW client branch and version.
- Atlas version.
- Atlas Transportation version.
- Affected map or transportation node.
- Steps to reproduce the issue.
- Relevant screenshots or Lua error messages.

Map corrections, translations, documentation improvements, and code
contributions are welcome.
